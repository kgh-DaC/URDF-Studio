사용 방법

  1. FreeCAD에서 내보낸 STL을 아래에서 단위 mm로 업로드
  2. 메시의 편집기에 링크 추가로 링크 조각 삽입(질량·관성·충돌 박스 자동)
  3. 조인트를 편집기에서 작성하면 자동 검증·3D 확인
  4. ROS 2 패키지 (zip) 을 받아 ros2_ws/src에 풀기
자연어 생성(Claude API)은 이 페이지에서 제공하지 않습니다. 로컬 서버판에서 사용하세요 → README
