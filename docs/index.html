URDF Studio

FreeCAD 모델과 STL 메시로 ROS 2 URDF를 만들고, 3D로 확인하고, 검증한 뒤 워크스페이스에 넣는 웹 앱입니다.

1. 내 컴퓨터에서 실행 중인 URDF Studio 열기

서버 확인 중…

포트 URDF Studio 열기

이 페이지는 웹 앱 서버를 대신 실행하지 못합니다. URDF 검증과 메시 계산은 내 컴퓨터의 Python 서버가 하기 때문에, 아래 2번으로 먼저 서버를 켜야 버튼이 활성화됩니다. 페이지는 127.0.0.1의 서버가 응답하는지만 확인하며 데이터를 보내지 않습니다.

2. 서버 켜기

  1. Python 3.11 이상을 설치합니다 (설치 화면에서 Add python.exe to PATH, py launcher 체크).
  2. 저장소를 받습니다. 저장소 폴더 안에서 아래를 실행하거나 ZIP을 풀어도 됩니다. 
    git clone https://github.com/kgh-DaC/urdf.git
cd urdf
  3. app\run.bat을 더블클릭합니다. 처음에는 패키지 설치로 몇 분 걸리고, 끝나면 브라우저가 자동으로 열립니다.

PowerShell을 쓰면 cd app 후 .\run.ps1. 실행 정책 오류 시 powershell -ExecutionPolicy Bypass -File .\run.ps1.

git clone https://github.com/kgh-DaC/urdf.git
cd urdf/app
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --port 8000

자연어 생성 기능을 쓰려면 서버를 켜기 전에 ANTHROPIC_API_KEY 환경변수를 설정합니다. 없어도 검증·3D 뷰어·메시 업로드·ZIP 내보내기는 동작합니다. 3D 뷰어는 CDN에서 three.js를 받으므로 인터넷이 필요합니다.

3. 작업 흐름

① FreeCAD링크 단위로 Body/Part를 만들고 export_parts.py 매크로로 STL과 parts.json을 내보냅니다.
② 업로드·분석STL을 올리고 단위(mm)와 밀도를 지정하면 질량·관성을 계산합니다.
③ URDF 작성·검증자연어로 생성하거나 편집기에서 수정합니다. 오류는 3D 뷰어의 링크 하이라이트로 표시됩니다.
④ ROS 2 반영ZIP을 받아 ros2_ws/src에 풀거나, 설치 스크립트로 검증 후 자동 배치합니다.

워크스페이스 자동 설치:

python -I .claude/skills/ros2-workspace-install/scripts/install_to_workspace.py ^
  --urdf output/robot.urdf --meshes meshes --ws C:\ros2_ws --dry-run

먼저 --dry-run으로 확인하고, 문제가 없으면 옵션을 빼고 실행합니다. 검증 오류가 있으면 설치되지 않습니다. 자세한 내용은 저장소의 README.md를 참고하세요.

문제 해결

  • 버튼이 계속 비활성화: 서버 창(검은 창)이 열려 있는지, 포트 번호가 서버와 같은지 확인합니다.
  • 3D 화면이 비어 있음: 인터넷 연결과 사내망의 CDN(jsdelivr) 차단 여부를 확인합니다.
  • 다른 호스트명으로 접속: URDF_APP_ALLOWED_HOSTS 환경변수에 호스트를 추가합니다.
